# Used Car Price Analysis (DWP Mini Project)

A beginner-friendly Data Wrangling and Preprocessing project using used-car listings. The project will inspect, clean, transform, and explore the data, then present findings in a Streamlit dashboard.

## Project structure

- `data/raw/` — original dataset; keep unchanged
- `data/processed/` — cleaned dataset created during the project
- `notebooks/` — inspection, cleaning, and analysis notebooks
- `dashboard/` — Streamlit app
- `report/` — final report and screenshots

## Dataset

Source: Kaggle, Vehicle Dataset from CarDekho. The local file used for this project is `data/raw/car_details_v3.csv`.

## Setup

Install the packages in `requirements.txt`, then open `notebooks/01_data_inspection.ipynb` in Jupyter and run the cells from top to bottom.
